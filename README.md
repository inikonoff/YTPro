# YT PRO (форк inikonoff)

Android-клиент YouTube на основе WebView с JS-инъекцией: блокировка рекламы, SponsorBlock, фоновое воспроизведение, скачивание видео, PiP, пересказ по автосубтитрам через Groq.

Форк [YTPRO](https://github.com/prateek-chaubey/YTPro) (MIT License, © Prateek Chaubey). Синхронизирован с оригиналом версии 4.0.0.

## Отличия от оригинала

- Скрипты (`scripts/`) упакованы в APK и не подгружаются из npm-пакета оригинала: приложение не меняется без пересборки.
- Убраны окно и проверка обновлений, баннеры и ссылки на автора.
- Жесты (`app/src/main/assets/ytpro-gestures.js`):
  - в полноэкранном режиме слева яркость (запоминается), справа громкость, центр нейтральный, свайп вниз из центра выходит из полноэкранного режима;
  - в обычном режиме свайп вверх по видео включает полноэкранный режим, свайп вниз сворачивает видео в окошко внутри приложения (`ytpro-miniplayer.js`): одним пальцем двигается, двумя меняет размер (30–90% ширины экрана), тап разворачивает, × останавливает;
  - кнопка или свайп «Назад» во время просмотра сворачивает видео в окошко, под ним список, из которого видео было открыто; следующие «Назад» листают список, потом закрывают окошко;
  - сворачивание приложения во время видео включает системный оконный режим (PiP);
  - поворот телефона горизонтально на видео включает полноэкранный режим, поворот обратно возвращает туда, откуда он был включён (страница или окошко); только при включённом автоповороте, для горизонтальных видео, на телефонах;
  - удержание пальца даёт скорость 2×, пока палец прижат;
  - pinch в полноэкранном режиме заполняет экран.
  - кнопка-«птичка» в левом верхнем углу полноэкранного режима плавно сворачивает видео в окошко и показывает список видео.

- Плавные анимации (`ytpro-motion.js`, мини-плеер, Java): экран запуска держится до загрузки страницы и растворяется, полноэкранный режим появляется и исчезает плавно, при свайпе вниз видео уменьшается вслед за пальцем, панели YTPro выезжают снизу. Системная настройка «Убрать анимацию» отключает их.
- Видео не встаёт на паузу при блокировке экрана и в фоне (`ytpro-bgfix.js`, при включённом Background Play).

## ИИ-помощник

Добавьте свой API-ключ Groq в настройках YTPro и нажмите «Проверить и сохранить». Приложение проверяет ключ запросом к модели `openai/gpt-oss-20b` через HTTPS relay проекта LINK. Ключ хранится в настройках Android и передаётся relay вместе с запросом. Для чтения и скачивания субтитров ключ не нужен.

Кнопка ИИ-помощника открывает пересказ по автоматической дорожке. Русская дорожка выбирается первой, если доступна. В меню скачивания субтитры доступны в TXT, SRT и XML.
